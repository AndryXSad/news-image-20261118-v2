## How it works

`entry.png` (1024×1024, rendered with PIL from verified reporting of
18 November 2026) is copied byte for byte to `/output/entry.png` by
`main.py` — Python 3.13, standard library only, no network, fully
deterministic.

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
